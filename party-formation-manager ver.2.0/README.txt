パーティ編成管理サイト（試作版）

【起動方法】
1. zipを展開します。
2. index.html をブラウザーで開きます。
   Google Fontsの読み込み以外は、外部ライブラリ不要です。ネット接続なしでも基本機能は動きます。

【使い方】
- 左側からステージ1〜12を選びます。
- キャラクター一覧のカードを押すと、そのステージに追加されます。
- 編成枠の × を押すと外せます。
- 属性ボタンで絞り込み、検索欄で名前検索できます。
- 上限回数に達したキャラクターは暗くなり、追加できません。
- 「このステージの編成をリセット」で選択中のステージだけ解除します。
- 「全編成をリセット」で全ステージを解除します。
- 編成データはブラウザーの localStorage に自動保存されます。

【データの編集】
character-data.js を編集してください。
- characters: キャラクターID・名前・表示用記号・属性3つ
- SEASONS: シーズンID・表示名・シーズンごとの特別枠4キャラクターID
- stages: 各ステージの有利属性2つと説明文
- ELEMENTS: 属性名とアイコン

【武器違いの登録】
同じキャラクターの武器違いを別カードにしたい場合、別々の id を与え、同じ parentId を指定してください。
例：
{ id: "char-a-sword", parentId: "char-a", name: "キャラA（剣）", symbol: "A剣", elements: ["火炎","風","雷"] }
{ id: "char-a-bow", parentId: "char-a", name: "キャラA（弓）", symbol: "A弓", elements: ["氷","大地","神聖"] }
同じ parentId の武器違いは使用回数を合算し、同一ステージでは重複編成できません。
特別枠を元キャラクター単位で適用したい場合は、SEASONS 内の specialCharacterIds にその parentId を追加してください。
（指定数は4人を想定しています。）

【注意】
- 現在のキャラクター名・属性・有利属性はすべて仮データです。実データに置き換えてください。
- 属性は現在、指定文に名前が挙がっていた8種類で作成しています。9種類目が決まったら ELEMENTS に追加できます。
- 使用回数は全12ステージを通して親キャラクター単位で合算します。

【シーズンの追加と保存】
character-data.js の SEASONS に新しい行を追加してください。
例：{ id: "season-2", name: "シーズン2", specialCharacterIds: ["char-001", "char-002", "char-003", "char-004"] },
画面右上のプルダウンからシーズンを切り替えられます。
各シーズンの12ステージ編成は個別にブラウザー内に保存されます。
「全編成をリセット」は現在のシーズンだけを対象とします。
既存のシーズンIDは変更しないでください。変更すると旧編成を読み出せなくなります。
旧バージョン(v1)の保存データは最初のシーズンに自動移行されます。
ブラウザーのデータ消去、別端末・別ブラウザー、閲覧モードなどでは編成が引き継がれない場合があります。
